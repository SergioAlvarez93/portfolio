# MPSTATS Top-50 Brands → Bitrix24

Node.js-скрипт для сбора аналитики брендов из MPSTATS по двум маркетплейсам — Wildberries и Ozon, формирования общего рейтинга Top-50 и синхронизации результата со смарт-процессом Bitrix24.

## Возможности

- Получение статистики брендов Wildberries через MPSTATS API.
- Получение статистики брендов Ozon через MPSTATS API.
- Нормализация названий брендов для сопоставления данных между площадками.
- Объединение показателей выручки и количества продаж.
- Расчёт средних показателей для брендов, присутствующих на обеих площадках.
- Сортировка по средней выручке и формирование Top-50.
- Сохранение исходных и объединённых данных в JSON.
- Создание, обновление и удаление элементов смарт-процесса Bitrix24.

## Стек

- Node.js (используется встроенный `fetch`; требуется Node.js 18 или новее).
- MPSTATS API.
- Bitrix24 REST API.
- dotenv.

## Настройка

1. Установите Node.js версии 18 или новее.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте `.env` на основе `.env.example`.
4. Заполните переменные окружения:

   ```env
   BASE_BITRIX=https://your-domain.bitrix24.ru/rest/USER_ID/WEBHOOK_TOKEN
   MPSTATS_TOKEN=your_mpstats_api_token
   ```

`BASE_BITRIX` — базовый URL входящего вебхука Bitrix24.  
`MPSTATS_TOKEN` — токен доступа к MPSTATS API.

Не публикуйте `.env` и не добавляйте реальные токены в репозиторий.

## Запуск

```bash
npm start
```

Скрипт выполняет полный цикл автоматически: запрашивает данные MPSTATS, объединяет показатели, формирует рейтинг и синхронизирует его с Bitrix24.

## Алгоритм работы

1. Запрашивает список брендов категории «Здоровье/БАДы» на Wildberries.
2. Запрашивает список брендов категории «Аптека/Витамины и БАДы» на Ozon.
3. Приводит названия брендов к нормализованному виду: удаляет пробельные и некоторые невидимые символы, переводит строку в нижний регистр.
4. Сопоставляет бренды между площадками.
5. Рассчитывает среднюю выручку и среднее количество продаж. Если бренд присутствует только на одной площадке, используется значение этой площадки.
6. Сортирует бренды по средней выручке по убыванию и оставляет первые 50 записей.
7. Получает существующие элементы смарт-процесса Bitrix24 с `entityTypeId = 1070`.
8. Обновляет найденные по названию бренда элементы, создаёт отсутствующие и удаляет элементы, которых нет в новом рейтинге.

## Выходные данные

Во время выполнения создаются JSON-файлы:

- `brands_wb_<date>.json` — данные Wildberries.
- `brands_ozon_<date>.json` — данные Ozon.
- `brands_merged_<date>.json` — объединённый рейтинг Top-50.

В Bitrix24 передаются название бренда, выручка и количество продаж по каждой площадке, а также рассчитанные средние показатели.

## Важные особенности и ограничения

- Скрипт рассчитан на конкретную конфигурацию MPSTATS и смарт-процесса Bitrix24. ID смарт-процесса и коды пользовательских полей заданы в исходном коде.
- Сопоставление брендов выполняется по нормализованному названию, без отдельного справочника алиасов. Различающиеся варианты написания одного бренда могут не объединиться.
- Перед синхронизацией скрипт получает список элементов смарт-процесса. После загрузки Top-50 он **удаляет все существующие элементы, названия которых отсутствуют в новом рейтинге**. Это поведение важно учитывать при запуске.
- В исходной реализации функции `getLast14DaysRange()` и `getYesterdayStr()` сдвигают дату примерно на 31 день назад; несмотря на названия, период не заканчивается вчерашним днём. Для рейтинга используется 14-дневный интервал, заканчивающийся на этой смещённой дате. Поведение сохранено без изменений.
- Скрипт сохраняет полученные данные в JSON в текущей рабочей директории.
- Для работы необходимы действующие доступы к MPSTATS и Bitrix24, а также доступность соответствующих API.

## Безопасность

Токены хранятся в `.env`, который исключён из Git через `.gitignore`. Файл `.env.example` содержит только шаблонные значения.

Если реальные токены из исходной версии уже передавались, публиковались или попадали в историю Git, их следует отозвать/перевыпустить. Простого удаления секретов из текущего файла недостаточно, если они уже были закоммичены ранее.

## Проверка

Синтаксис JavaScript проверяется командой:

```bash
node --check index.js
```

Проверка синтаксиса не подтверждает доступность MPSTATS/Bitrix24 и не заменяет тестовый запуск с действующими учётными данными.
