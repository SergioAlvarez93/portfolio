# EAEU SGR Company Search

Node.js-скрипт для поиска компаний и их продукции в Едином реестре свидетельств о государственной регистрации (СГР) ЕАЭС через API.

В качестве исходных данных используется Excel-файл со списком компаний. Скрипт выполняет поиск по реестру, обрабатывает результаты, проверяет совпадение названий производителей и исключает записи с аннулированными или отозванными статусами.

## Возможности

- Загрузка списка компаний из `companies.xlsx`.
- Поиск в API реестра СГР по точному совпадению (`eq`).
- Дополнительный поиск по ключевому слову (`like`).
- Нормализация названий компаний с учётом регистра, пунктуации, кавычек, пробелов, организационно-правовых форм и адресных уточнений.
- Постраничное получение результатов API с обработкой больших выборок.
- Объединение результатов поиска и устранение дубликатов по ID записей.
- Проверка полного совпадения нормализованных названий производителей.
- Исключение записей со статусами, содержащими «аннулирован» или «отозван».
- Экспорт найденных записей в Excel.

## Технологии

- Node.js
- JavaScript
- Axios
- SheetJS (`xlsx`)
- REST API Единого реестра СГР ЕАЭС

## Входные данные

Файл `companies.xlsx` должен находиться в корневой директории проекта.

Скрипт использует первый лист Excel-книги и ожидает столбец с заголовком `Компания`.

Пример:

| Компания        |
| --------------- |
| ООО «Пример»    |
| АО Ромашка      |
| Производитель N |

## Установка и запуск

Установить зависимости:

```bash
npm install
```

Поместить `companies.xlsx` в директорию проекта и запустить:

```bash
node index.js
```

## Алгоритм работы

1. Читает список компаний из Excel.
2. Нормализует названия компаний, устраняя различия в написании.
3. Извлекает наиболее подходящее ключевое слово для дополнительного поиска.
4. Выполняет запросы к API реестра с условиями точного и частичного совпадения.
5. Объединяет результаты запросов, исключая дубликаты.
6. Сравнивает нормализованные названия производителей с исходным списком компаний.
7. Исключает записи с аннулированными и отозванными статусами.
8. Формирует итоговый набор данных и сохраняет его в `sgr_filtered.xlsx`.

## Результат

Итоговый Excel-файл `sgr_filtered.xlsx` содержит сведения о найденных записях СГР:

- ID записи;
- номер и серия документа;
- дата документа;
- статус регистрации;
- наименование производителя;
- наименование получателя;
- наименование продукции;
- нормативные сведения и область применения;
- данные протокола;
- даты действия и обновления записи.

## Особенности

Поиск выполняется по полю `FIRMMADE_NAME`. Дополнительный поиск по ключевому слову позволяет получить расширенный набор кандидатов, после чего локальная нормализация и проверка полного совпадения помогают отсеять нерелевантные результаты.

Для ограничения нагрузки на API предусмотрены постраничная загрузка, паузы между запросами и ограничение максимального количества страниц.

Скрипт ориентирован на конкретную структуру API реестра СГР ЕАЭС. Изменения API могут потребовать адаптации обработки ответа.

## Безопасность

Файл `companies.xlsx` может содержать внутренний перечень контрагентов. Не рекомендуется публиковать его в открытом репозитории.

В `.gitignore` следует добавить:

```gitignore
node_modules/
companies.xlsx
sgr_filtered.xlsx
```
