# 1C Production Stock Analyzer

Десктопное приложение для получения складских остатков и данных о клиентских заказах из 1С, формирования сводного отчёта и последующего анализа данных с помощью DeepSeek.

## Возможности

- Получение списка складов и складских остатков через HTTP API 1С.
- Получение клиентских заказов за выбранный период.
- Выбор одного или нескольких складов в графическом интерфейсе.
- Проверка выбранных складов на дубликаты.
- Агрегация остатков по номенклатуре и формирование сводки.
- Отображение состава продукции, компонентов и вложенных субкомпонентов.
- Сохранение отчёта в текстовый файл.
- Копирование сформированного отчёта в буфер обмена.
- Встроенная вкладка DeepSeek для передачи отчёта на анализ и подготовки рекомендаций по распределению складских остатков для производственных потребностей.

## Сценарий работы

1. Приложение подключается к API 1С и загружает доступные склады.
2. Пользователь выбирает склады и период, за который необходимо получить заказы.
3. Приложение запрашивает складские остатки и клиентские заказы.
4. Данные обрабатываются: остатки группируются по номенклатуре, заказы выводятся вместе с составом продукции и необходимыми компонентами.
5. Приложение формирует текстовый отчёт и сохраняет его локально.
6. Пользователь может скопировать отчёт и передать его в DeepSeek во встроенной вкладке для анализа и получения стратегии распределения остатков.

> Приложение открывает веб-интерфейс DeepSeek, но не отправляет данные в модель автоматически. Передача отчёта выполняется пользователем вручную через буфер обмена.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <repository-directory>
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте локальный файл `.env` на основе `.env.example` и укажите параметры подключения к 1С.

```bash
cp .env.example .env
```

В Windows файл можно скопировать вручную:

```powershell
Copy-Item .env.example .env
```

### 5. Запуск

```bash
python main.py
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `ONE_C_BASE_URL` | Базовый URL HTTP-сервисов 1С, включая путь до группы сервисов |
| `ONE_C_LOGIN` | Логин для Basic Authentication |
| `ONE_C_PASSWORD` | Пароль для Basic Authentication |
| `DEFAULT_WAREHOUSES` | Склады, выбранные по умолчанию, через запятую |
| `DEEPSEEK_URL` | URL веб-интерфейса DeepSeek |

Пример заполнения находится в `.env.example`. Не добавляйте рабочий `.env` в Git.

## Формат данных и отчёта

Приложение использует JSON-ответы API 1С. Для складских остатков ожидается объект с массивом `warehouses`, содержащим склады и их `items`. Для заказов ожидается объект с массивом `orders`, содержащим позиции заказов и их компоненты.

На основе полученных данных формируется локальный текстовый отчёт, включающий:

- остатки по выбранным складам;
- сводное количество позиций и уникальной номенклатуры;
- TOP-20 материалов по абсолютному количеству;
- заказы за выбранный период;
- статусы продукции;
- состав продукции и иерархию компонентов.

## Безопасность

- Рабочие URL, логин и пароль задаются через `.env`.
- Файл `.env` исключён из Git.
- Не публикуйте реальные ответы API, отчёты, выгрузки, данные клиентов и внутренние адреса инфраструктуры.
- Не добавляйте в репозиторий пароли, токены и другие секреты.
- Перед публикацией проверьте историю Git: удаление секрета из текущей версии файла не удаляет его из предыдущих коммитов.
- Если секрет уже был опубликован, замените или отзовите его.

## Ограничения

- Структура обрабатываемых данных зависит от формата ответов конкретной конфигурации 1С.
- Для работы необходима доступность API 1С и корректные права учётной записи.
- Анализ в DeepSeek выполняется пользователем вручную: приложение подготавливает данные и предоставляет встроенную вкладку веб-интерфейса.
- Встроенный браузер DeepSeek зависит от доступности сервиса и его совместимости с Qt WebEngine.

## Назначение

Проект автоматизирует сбор и подготовку данных о складских остатках и заказах, чтобы упростить анализ обеспеченности производства материалами и помочь при планировании распределения ресурсов.
