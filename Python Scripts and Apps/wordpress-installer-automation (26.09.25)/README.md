# WordPress Installer Automation

Desktop-приложение на Python/Tkinter для автоматизированного развёртывания локального WordPress-проекта в OSPanel.

## Возможности

- Проверка и перезапуск OSPanel.
- Создание каталога проекта.
- Загрузка актуального русскоязычного архива WordPress.
- Распаковка ядра WordPress в каталог проекта.
- Создание служебных каталогов OSPanel и `project.ini`.
- Создание базы данных через интерфейс phpMyAdmin с помощью Selenium.
- Прохождение веб-установщика WordPress.
- Генерация пароля администратора.
- Установка локального шаблона темы из выбранной папки.
- Копирование заранее подготовленного набора плагинов.
- Формирование файла с параметрами доступа.
- GUI с отображением этапов установки и логированием.

## Стек

Python, Tkinter/ttk, Selenium WebDriver, webdriver-manager, wget, OSPanel, WordPress, phpMyAdmin.

## Требования

- Windows и установленный OSPanel.
- Google Chrome.
- Python 3.9+.
- Локальные папки с заготовкой темы и плагинами.
- Доступность `ru.wordpress.org` и локальных доменов OSPanel (`*.local`, `phpmyadmin.local`).

## Установка

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\\Scripts\\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
python wordpress_installer.py
```

## Сценарий работы

1. Укажите имя проекта латиницей.
2. Выберите каталог установки OSPanel.
3. Выберите каталог, в котором будут создаваться проекты.
4. Укажите папку с заготовкой WordPress-темы.
5. Укажите папку с подготовленными плагинами.
6. Введите email для учётной записи администратора WordPress.
7. Нажмите «Установить».

Приложение загружает WordPress, создаёт локальную структуру проекта и базу данных, проходит установщик, затем копирует тему и плагины.

## Важные замечания по безопасности

- Приложение создаёт `access.txt` внутри каталога темы. В этот файл записываются email, пароль почты, логин и пароль администратора WordPress, а также имя базы данных. **Не публикуйте этот файл и не добавляйте его в Git.**
- В исходном сценарии пароль администратора также записывается в `wordpress_installer.log`. Поэтому лог может содержать секретные данные — не публикуйте его.
- Для портфолио в репозитории оставлен только исходный код. Реальные учётные данные и локальные файлы проектов в репозиторий добавлять нельзя.
- Установка рассчитана на конкретное локальное окружение OSPanel и phpMyAdmin; параметры PHP, MySQL и локальные домены зависят от конфигурации установленной среды.
- Selenium-сценарии зависят от HTML-разметки интерфейса phpMyAdmin и установщика WordPress. При изменениях интерфейса локаторов может потребоваться обновление.

## Ограничения

Это локальный автоматизатор развёртывания, а не универсальный установщик для production-хостинга. Сценарий использует браузерную автоматизацию для управления phpMyAdmin и установщиком WordPress.
